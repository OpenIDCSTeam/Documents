# About OpenIDCS

OpenIDCS (Open Internet Data Center System) is an open-source IDC virtualization management platform.

## Principles

1. **Simple first** — single binary, single database, few dependencies.
2. **Explicit capabilities** — what a platform supports is declared in metadata.
3. **One API** — console, CLI and plugins share it.
4. **Operable** — tasks, logs, reconciliation and tombstones.
5. **Open** — AGPLv3, extensible drivers and plugins.
