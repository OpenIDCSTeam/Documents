# Docker / LXC：不需要爱快

容器平台不用接爱快。Docker 和 LXC 直接在宿主机上分配地址、做端口映射，爱快那套 DHCP / ARP 绑定用不上，硬接反而多一跳。

## Docker

- 默认 `bridge` 网络，容器拿 `172.17.0.0/16` 的地址，对外用 `-p` 发布端口；
- 需要容器有独立内网 IP 时用 `macvlan`，父接口填宿主机内网网卡；
- 公网暴露交给主控的[端口转发](/usage/nat)或[反向代理](/usage/proxies)。

## LXC / LXD

- LXD 自带 `lxdbr0`，地址池与 NAT 规则由 LXD 管理，容器直连即可；
- 需要和宿主机同网段时，把容器挂到宿主机的网桥（例如 `br0`）；
- 对外同样走主控的端口转发，不用再加一层软路由。

## 什么时候才需要爱快

要统一分配独立公网 IP 段、按实例做 ARP 绑定和上下行限速，才会在宿主机前面放一台 iKuai。只跑容器、只做端口映射的场景，直接省略这一步。

安卓模拟器（MEmu）这类本机运行时同理，不需要爱快。
