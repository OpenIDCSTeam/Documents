# Hyper-V 网卡配置

Hyper-V 用虚拟交换机分内外网：外部交换机绑公网网卡，内部交换机只给虚拟机之间用。

## 建交换机

Hyper-V 管理器 → 虚拟交换机管理器：

| 类型 | 名称 | 绑定 |
|---|---|---|
| 外部 | `WAN-Switch` | 公网物理网卡，勾选「允许管理操作系统共享此网络适配器」 |
| 内部 | `LAN-Switch` | 不绑物理网卡 |

内部交换机建好后，主机上会多一块 `vEthernet (LAN-Switch)` 虚拟网卡。把它设成「不配置 IP」或换一个和内网不冲突的网段，否则会和 iKuai 抢网关。

## 挂到 iKuai

iKuai 虚拟机 → 设置 → 添加硬件 → 网络适配器：

- 适配器 1 → `WAN-Switch`
- 适配器 2 → `LAN-Switch`

两块都用默认的「网络适配器」即可，不需要旧版适配器。

## 验证

- iKuai 控制台 eth0、eth1 都是「已连接」；
- 宿主机上 `Get-VMNetworkAdapter -VMName <iKuai 虚拟机名>` 能看到两块网卡分别接在两个交换机上。
