# VMware Workstation 网卡配置

Workstation 用 `VMnet0`（桥接）接公网，`VMnet1`（仅主机）接内网。

## 建网络

编辑 → 虚拟网络编辑器（需要管理员权限）：

| 虚拟网络 | 类型 | 说明 |
|---|---|---|
| VMnet0 | 桥接 | 桥接到公网物理网卡 |
| VMnet1 | 仅主机 | 取消「使用本地 DHCP 服务」，地址由 iKuai 分配 |

VMnet1 的子网换成和内网不冲突的网段，或者干脆不给宿主机配地址。

## 挂到 iKuai

iKuai 虚拟机 → 设置 → 网络适配器：

| 网卡 | 网络连接 | 高级设置 |
|---|---|---|
| 网卡 1（公网） | 桥接（VMnet0 → 公网网卡） | 保持默认 |
| 网卡 2（内网） | 仅主机（VMnet1） | 保持默认 |

## 验证

- iKuai 控制台 eth0、eth1 均为「已连接」；
- 宿主机能打开 iKuai 的 Web 管理页。
