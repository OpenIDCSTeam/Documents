# 任务管理

任务管理展示所有异步操作的进度、结果与错误，是排障的第一入口。

## 列表页

`/tasks`

| 列 | 说明 |
|---|---|
| 任务 ID | 唯一标识 |
| 类型 | 创建 / 删除 / 重装 / 备份 / 恢复 / 同步 |
| 资源 | 主机 + 实例 |
| 状态 | 等待 / 运行 / 成功 / 失败 / 已取消 |
| 进度 | 0–100% |
| 创建时间 | — |
| 操作 | 详情、取消、重试 |

筛选：状态、类型、主机、时间范围、关键字。

## 任务详情

- **步骤时间线**：每一步的开始/结束时间与结果；
- **原始错误**：平台返回的 stderr / API 错误；
- **关联资源**：点击跳转主机或实例；
- **重试**：仅对幂等任务开放（如同步、备份）；
- **取消**：运行中可请求取消，是否立即生效取决于平台。

## 常见任务类型

| 类型 | 触发 | 幂等 |
|---|---|---|
| `create` | 新建实例 | 否 |
| `delete` | 删除实例 | 是（墓碑） |
| `reinstall` | 重装 | 否 |
| `backup` | 创建备份 | 是 |
| `restore` | 恢复备份 | 否（覆盖） |
| `sync` | 同步主机实例 | 是 |
| `scan` | 扫描/纳管 | 是 |

## 任务卡住怎么办

1. 看详情最后一步与错误；
2. 检查主机是否在线；
3. 检查平台侧是否已有同名资源；
4. 可取消则取消，再重试；
5. 删除类任务失败可等待对账任务自动收敛。

::: tip 不要反复点「重试」
非幂等任务（创建/重装）反复重试可能产生重复资源。先确认平台侧状态。
:::

## 后台任务

系统还会运行定时任务（同步、配额重算、对账、截图清理），它们不一定出现在列表，可在系统设置查看执行记录。

## 命令行

```bash
opidcs task list
opidcs task list --status running
opidcs task cancel <task-id>
```
