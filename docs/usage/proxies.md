# 反向代理

反向代理把域名指向实例端口，由主控托管的 Caddy 负责 TLS 与转发。适合 Web 面板、API、站点。

## 列表页

`/web-proxys`（管理员）或 `/user/proxys`（用户）。

| 列 | 说明 |
|---|---|
| 域名 | 对外访问域名 |
| 主机 / 实例 | 目标资源 |
| 上游 | `IP:端口` |
| 证书 | 已签发 / 待签发 / 失败 |
| 状态 | 已启用 / 已停用 |
| 操作 | 编辑、停用、删除 |

## 新增代理

| 字段 | 说明 | 示例 |
|---|---|---|
| 域名 | 必须已解析到主控/入口 IP | `app.example.com` |
| 主机 | 目标实例所属主机 | `pve-lab` |
| 实例 | 目标实例 | `web-01` |
| 上游端口 | 实例内监听端口 | `8080` |
| 协议 | HTTP / HTTPS | `http` |
| 路径 | 可选前缀 | `/` |
| 启用 HTTPS | 是否由 Caddy 签发 | 是 |

## 证书

- Caddy 通过 ACME 申请证书，需要 80/443 可达；
- 域名未解析或 80 被封时签发失败；
- 已有证书可放到 Caddy 的证书目录并手动引用；
- 证书续期由 Caddy 自动完成。

::: warning 主控端口
Caddy 管理端口 `2019` 只监听本机；对外只开放 80/443。不要把 2019 暴露到公网。
:::

## 直连与中转

主机配置的 `proxy_mode` 决定上游地址：

- `direct`：上游 = 实例内网 IP；
- `relay`：上游 = 爱快中转地址，再由爱快 DNAT 到实例。

如果实例在爱快后面且主控不在同网段，必须选 `relay`。

## 用户侧

普通用户只能管理自己实例的代理：

- 新建时实例列表只有自己的；
- 不能修改域名后缀（由管理员在设置中限定）；
- 删除需二次确认。

## 命令行

```bash
opidcs webx list
opidcs webx list --host pve-lab
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 502 | 上游端口不对 / 实例未监听 |
| 证书一直待签发 | 检查域名解析与 80 端口 |
| 403 | 路径或来源限制 |
| 修改不生效 | Caddy 重载失败，查看任务与日志 |
