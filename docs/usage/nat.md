# 端口转发

端口转发（NAT）把公网端口映射到实例内网端口，适合没有独立公网 IP 的场景。

## 列表页

`/nat-rules`（管理员）或 `/user/nat`（用户）。

| 列 | 说明 |
|---|---|
| 主机 | 规则所属 `hs_name` |
| 实例 | 实例名 / UUID |
| 协议 | TCP / UDP |
| 公网端口 | 对外端口 |
| 内网端口 | 实例端口 |
| 状态 | 已生效 / 待下发 / 失败 |
| 操作 | 删除、查看详情 |

## 新增规则

1. 选择主机；
2. 选择实例（只显示该主机下实例）；
3. 选择协议；
4. 填公网端口与内网端口；
5. 可选备注；
6. 提交。

::: tip 端口冲突
同一主机的同一公网端口 + 协议只能被一条规则占用；冲突会在提交时提示。
:::

## 下发行为

| 平台 | 下发方式 |
|---|---|
| Proxmox / QEMU | 宿主机 iptables DNAT |
| LXD | 宿主机 iptables / proxy device |
| Docker | 宿主机 iptables 或 socat |
| 爱快 | 爱快端口映射 API |
| Hyper-V | Windows NAT / 端口代理 |

下发失败会在规则状态标红，并记录任务。

## 删除

- 删除规则会同时移除平台侧映射；
- 删除实例时可选择一并删除其规则；
- 失败重试入口：任务管理。

## 与反向代理的区别

| 维度 | 端口转发 | 反向代理 |
|---|---|---|
| 协议 | TCP / UDP | HTTP / HTTPS |
| 域名 | 不支持 | 支持 |
| 证书 | 不涉及 | Caddy 自动签发 |
| 适用 | SSH、游戏服、数据库 | Web、面板、API |

两者可以同时存在：Web 走反代，SSH 走端口转发。

## 命令行

```bash
opidcs port list --host pve-lab
opidcs port add --vm <uuid> --proto tcp --public 20022 --private 22
opidcs port del <rule-id>
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 规则已建但连不上 | 检查平台防火墙与爱快 DNAT |
| 端口被占用 | 换端口或删除冲突规则 |
| 下发失败 | 查看任务错误（权限/命令不存在） |
| 外网通内网不通 | 检查回流（hairpin）配置 |
