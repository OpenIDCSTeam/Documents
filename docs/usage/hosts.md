# 主机管理

主机管理是「把宿主机接进平台」的入口。每台主机对应一种虚拟化引擎与一组连接参数。

## 列表页

| 列 | 说明 |
|---|---|
| 名称 | `hs_name`，全局唯一 |
| 类型 | 引擎类型（Docker / LXD / PVE / ESXi …） |
| 地址 | `host[:port]` |
| 状态 | 在线 / 离线 / 维护中 |
| 实例数 | 已纳管实例数量 |
| 操作 | 详情、编辑、启停、删除、扫描 |

状态为离线时，鼠标悬停可看到最近一次探测错误。

## 新增主机

点击「新增」，表单分四个分组：

### 1. 基本配置

| 字段 | 必填 | 说明 |
|---|---|---|
| 服务器名称 | ✅ | 唯一标识，建议 `平台-序号` |
| 服务器类型 | ✅ | 决定后续字段 |
| 服务器地址 | ✅ | `host[:port]`；本机可填 `localhost` |
| 服务器用户 | 远程必填 | SSH / API 账号 |
| 服务器密码 | 远程必填 | — |
| 虚拟机前缀 | 建议 | 只纳管带该前缀的实例 |
| 服务访问端口 | 视平台 | API 端口 |
| 服务器公网IP | 建议 | 多个用逗号分隔 |
| 反向代理模式 | 建议 | `直连` / `经爱快中转` |
| 中转地址 | 中转时 | 留空取公网 IP |
| VNC 反代IP / 外网地址 | 可选 | 控制台对外地址 |
| 共享/独立IP设备名 | 可选 | 爱快设备名 |
| 区域代码 / 名称 | 可选 | 用于分组展示 |

### 2. 存储路径

| 字段 | 说明 |
|---|---|
| 模板存储路径 | 镜像 / rootfs |
| 光盘存储路径 | ISO |
| 系统存储路径 | 系统盘 |
| 备份存储路径 | 备份文件 |
| 数据存储路径 | 数据盘 |
| 程序启动路径 | 如 memuc / VBoxManage |

### 3. 网络与爱快

| 字段 | 说明 |
|---|---|
| 爱快OS地址 / 用户名 / 密码 | 用于 DHCP 静态绑定与 NAT |
| TCP端口起始 / 结束 | NAT 分配区间 |
| VNC服务端口 | 起始端口 |
| 虚拟机数量限制 | 防超卖 |
| DNS服务器 | 下发或展示用 |

### 4. 价格（可选）

按 CPU / 内存 / 磁盘 / 流量设置单价，用于展示或对接计费。

## 保存后

1. 主控会立即探测一次状态；
2. 在线后可点「扫描实例」把平台已有实例纳入；
3. 建议创建一台测试实例验证控制台与网络。

## 编辑与删除

- **编辑**：平台类型不可改（需删除重建），其余字段可改；
- **禁用**：保留记录但不允许新建实例；
- **删除**：需先清空实例，或选择「同时删除平台实例」（危险）。

## 扫描与备份

| 操作 | 作用 |
|---|---|
| 扫描实例 | 对比平台与主控记录，新增/更新实例 |
| 扫描备份 | 发现平台侧已有备份文件 |
| 导出配置 | 导出主机配置为 YAML，便于迁移 |
| 导入配置 | 从 YAML 恢复主机（不含凭据时需重填） |

## 命令行

```bash
opidcs host list
opidcs host add --name pve-lab --type PromoxSetup --addr 10.0.0.21:8006 --user root@pam
opidcs host status pve-lab
opidcs host scanvm pve-lab
opidcs host export pve-lab --file pve-lab.yaml
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 一直离线 | 检查地址/端口/账号，确认主控能访问 |
| 类型选错 | 删除重建（类型不可改） |
| 扫描不到实例 | 检查 `filter_name` 前缀 |
| 无法创建 | 检查实例上限与配额 |
