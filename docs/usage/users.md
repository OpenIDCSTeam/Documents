# 用户管理

管理员在 `/users` 管理用户、配额与状态；普通用户在 `/profile` 维护自己的资料。

## 列表页

| 列 | 说明 |
|---|---|
| 用户名 | 登录名 |
| 邮箱 | 联系方式 |
| 角色 | 管理员 / 普通用户 |
| 状态 | 启用 / 禁用 |
| 实例数 | 归属该用户的实例 |
| 配额 | CPU / 内存 / 磁盘 / 流量 |
| 操作 | 编辑、重置密码、禁用、删除 |

## 新建用户

| 字段 | 必填 | 说明 |
|---|---|---|
| 用户名 | ✅ | 唯一，创建后不可改 |
| 密码 | ✅ | 建议强密码 |
| 邮箱 | 建议 | 用于找回密码 |
| 角色 | ✅ | 默认普通用户 |
| 配额 | 建议 | 不填则继承全局默认 |
| 备注 | 可选 | — |

## 配额

| 配额 | 说明 |
|---|---|
| CPU | 所有实例核数之和 |
| 内存 | 所有实例内存之和（MB） |
| 磁盘 | 系统盘 + 数据盘（GB） |
| 实例数 | 实例记录数 |
| 流量 | 月度累计（GB） |

- 创建/修改实例时校验，超出则拒绝；
- 管理员可点「重算配额」修正历史误差；
- 调低配额不会删除已有实例，但会阻止继续创建。

## 状态与密码

| 操作 | 效果 |
|---|---|
| 禁用 | 禁止登录，实例保留 |
| 启用 | 恢复登录 |
| 重置密码 | 生成临时密码或指定新密码 |
| 强制下线 | 使当前会话失效（视版本） |

## 删除用户

::: danger 不可恢复
删除用户前请先转移或删除其实例。默认策略是「有实例时禁止删除」，避免资源失去归属。
:::

## 普通用户视角

| 页面 | 能力 |
|---|---|
| 资源概览 | 查看自己的配额与用量 |
| 实例管理 | 开关机、控制台、重装（若允许） |
| 端口转发 | 管理自己实例的规则 |
| 反向代理 | 管理自己实例的域名 |
| 个人资料 | 修改邮箱、密码 |

## 注册与找回密码

- 注册入口可在系统设置中关闭；
- 找回密码依赖 SMTP 配置；
- 邮件验证链接有效期由设置决定。

## 命令行

```bash
opidcs user list
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 用户看不到实例 | 检查归属与共享关系 |
| 配额显示为 0 | 执行「重算配额」 |
| 收不到邮件 | 检查 SMTP 与垃圾箱 |
| 无法删除用户 | 先转移实例 |
