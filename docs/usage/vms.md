# 实例管理

实例管理覆盖创建、查看、控制台、电源、存储、网络、备份与共享。列表页在 `/vms`，详情在 `/hosts/:hostName/vms/:uuid`。

## 列表页

| 列 | 说明 |
|---|---|
| 名称 | 实例名（创建时指定） |
| 主机 | 所属 `hs_name` |
| 状态 | 运行 / 停止 / 暂停 / 异常 |
| 规格 | CPU / 内存 / 磁盘 |
| IP | 主控记录或 Agent 上报 |
| 操作 | 开机、关机、控制台、删除 |

筛选：按主机、状态、关键字；支持批量选择。

## 创建实例

点击「新建」，四步向导：

### 1. 选择主机

只显示在线且启用的主机。平台限制会即时提示（如 LXD 不支持 GPU）。

### 2. 选择镜像

来源：主机的 `images_path` 或平台镜像列表。没有镜像时先去 [镜像部署](/deploy/images)。

### 3. 规格

| 字段 | 说明 | 受限平台 |
|---|---|---|
| CPU | 核数 | 全部 |
| 内存 | MB | 全部 |
| 系统盘 | GB | 全部 |
| 带宽 | Mbps | Docker/LXD/SmolVM 不支持 |
| GPU / 显存 | 数量 / MB | 容器类不支持 |
| 数据盘 | 数量 / 大小 | LXD 不支持 |
| IP 数量 | 独立 IP | 视网络 |

被 `ban_init` 禁用的字段不会出现，不要试图绕过。

### 4. 初始化

| 字段 | 说明 |
|---|---|
| 主机名 | 默认同实例名 |
| 用户名 | CloudInit 创建的用户 |
| 密码 | 初始密码 |
| SSH 公钥 | 可多行 |
| 自定义脚本 | cloud-init `runcmd` |
| 网络 | DHCP / 静态 IP |

提交后进入任务队列，列表会显示「创建中」。

## 详情页页签

| 页签 | 内容 |
|---|---|
| 概览 | 状态、规格、镜像、IP、到期时间 |
| 监控 | CPU / 内存 / 磁盘 / 网络曲线 |
| 控制台 | noVNC 窗口、Web SSH |
| 存储 | 磁盘、ISO、USB |
| 网络 | IP、NAT、反代、DNS |

| 共享 | 所有者、共享者与权限 |

| 设置 | 修改配置、重装、删除 |

## 电源与生命周期

| 按钮 | 行为 | 注意 |
|---|---|---|
| 开机 | start | — |
| 关机 | 正常关机 | 需要 guest 支持 |
| 强制断电 | poweroff | 可能丢数据 |
| 重启 | restart | — |
| 硬重启 | reset | 视平台 |
| 暂停 / 恢复 | pause / resume | MuMu 不支持 |
| 重装 | reinstall | 系统盘重建 |
| 删除 | delete | 写入墓碑，异步回收 |

## 控制台

- **noVNC**：浏览器内操作，支持 Ctrl+Alt+Del、剪贴板、全屏；
- **Web SSH**：适合 Linux，支持复制粘贴；
- **RDP / ADB**：Hyper-V / Workstation / MuMu 显示连接信息。

## 修改配置

- 运行中修改 CPU / 内存通常需要重启；
- 磁盘只能扩容，不能缩容；
- 带宽限制修改即时生效（平台支持时）；
- 修改镜像不会重装，重装请用「重装系统」。

## 共享与访问密钥

见 [共享与访问密钥](/features/access)：

- 转移所有者；
- 添加共享者并设置只读 / 控制台 / 管理；
- 生成 16 位访问密钥供用户自助登录。

## 批量操作

勾选多个实例后可：

- 批量开机 / 关机；
- 批量删除（需输入确认）；
- 批量加入同一反代规则（仅同主机）。

## 命令行

```bash
opidcs vm list --host pve-lab
opidcs vm add --host pve-lab --image debian12 --cpu 2 --mem 2048 --disk 40
opidcs vm power start <uuid>
opidcs vm power stop <uuid>
opidcs vm show <uuid>
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 创建卡在 0% | 看任务详情里的平台错误 |
| 开机后无 IP | 检查 DHCP / Agent 上报 |
| 控制台黑屏 | 平台 VNC 端口或实例未启动 |
| 删除失败 | 平台侧仍存在，查看墓碑对账 |
