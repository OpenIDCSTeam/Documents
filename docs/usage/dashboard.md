# 系统概览

登录后的默认页，用于快速判断「平台是否健康、资源是否够用、有没有失败任务」。

## 页面组成

| 区块 | 内容 | 数据来源 |
|---|---|---|
| 顶部指标 | 主机数、实例数、运行中、用户数 | `GET /api/system/statis` |
| 资源卡片 | CPU / 内存 / 磁盘 / 流量 | `GET /api/system/stats` |
| 趋势图 | 近 24 小时资源曲线（视采样） | 同上 |
| 最近任务 | 最近 10 条任务及状态 | `GET /api/tasks` |
| 告警区 | 离线主机、失败任务、异常实例 | 聚合计算 |

## 怎么读这些数字

- **主机在线数**：状态由驱动实时探测，离线会标红；
- **实例运行中**：平台真实状态，不是主控记录的「期望状态」；
- **CPU / 内存**：宿主机维度，超卖时看「已分配 vs 实际」；
- **流量**：按实例累计，月初重置（可在设置中调整）。

::: tip 数字对不上怎么办
先看「主机管理」里主机是否在线，再看「任务管理」是否有失败任务。概览页的数字是聚合值，主机离线时会退化为缓存。
:::

## 快捷操作

- 点击主机卡片跳转主机详情；
- 点击实例数跳转实例列表并按状态过滤；
- 点击失败任务直接打开任务详情；
- 右上角可切换时间范围（1h / 24h / 7d）。

## 用户视图

普通用户的「资源概览」只展示自己的实例与配额：

| 指标 | 说明 |
|---|---|
| 我的实例 | 运行 / 停止 / 总数 |
| 配额使用 | CPU / 内存 / 磁盘 / 流量 |
| 到期提醒 | 临近到期的实例（如启用计费） |
