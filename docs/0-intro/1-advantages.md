# 产品特点

功能清单见[功能介绍](/intro/features)。这一页讲这套东西跟同类方案的差别在哪。

## 主控交付

CloudHost 编译成单个可执行文件 `hostagent`，默认 SQLite（`data/data.db`），也能换成 MySQL 或 PostgreSQL。静态前端和 noVNC 页面随主控一起发布，不额外部署 Web 服务；Linux 有安装脚本注册 systemd，Windows 安装包注册系统服务。升级只替换二进制，数据目录原样保留。

## 平台适配

每个平台一个独立驱动，配一份 `engine_config` 能力表。表单出现哪些字段（GPU、显存、带宽、ISO、数据盘）、哪些操作能点（暂停、USB 直通、备份）、哪些页签锁住（PCI / USB / EFI / HDD），全由这份配置决定，FrontPage 照着渲染，不写死平台判断。

平台升级带来新能力时，改配置即可，前端不用跟着发版；平台做不到的事也不会在界面上露出来。

## 扩展方式

主控、前端、Agent 和插件都按 AGPLv3 发布。加平台就实现 `HostDriver` 接口；接财务系统就调主控 REST API 写插件；补运维命令就扩 `quickidc` 的命令表。

## 方案比较

| 维度 | 快简云（Quick IDC） | 单平台面板（如 PVE 自带） | 通用云管平台 |
|---|---|---|---|
| 多平台纳管 | 10+ 平台 | 单一平台 | 通常支持多平台 |
| 部署成本 | 单二进制 + SQLite | 中 | 高，依赖多组件 |
| 财务插件 | 已提供多种插件 | 通常无 | 通常需定制 |
| 二次开发 | Go + React | 受产品限制 | 视产品而定 |

只用一个虚拟化平台、也不对外卖资源时，平台自带面板够用。要同时管多种平台，或者要把资源接到财务系统里卖，再评估快简云。
