# 产品特点

## 主控交付

CloudHost 编译为可执行文件 `hostagent`，默认使用 SQLite（`data/data.db`），也支持 MySQL 和 PostgreSQL。

- 静态前端与 noVNC 页面随主控发布；
- Linux 安装脚本可注册 systemd 服务；
- Windows 安装包可注册系统服务。

## 平台适配

每个平台使用独立驱动和能力配置（`engine_config`）。主控按配置提供字段和操作：

- 字段包括 GPU、显存、带宽、ISO 和数据盘；
- 操作限制包括暂停、USB 直通和快照备份；
- PCI、USB、EFI、HDD 等页签可按平台能力启用或禁用。

FrontPage 根据能力配置显示表单和操作状态。

## 网络组件

- **NAT 端口转发**：按实例维护规则，支持批量下发与回收。
- **爱快联动**：提供 DHCP 静态绑定与 ARP 绑定。
- **反向代理**：主控管理 Caddy 进程与 `Caddyfile`，可为用户域名签发证书。
- **VNC / SSH**：主控提供 6080 和 7681 代理端口，用户不必直接连接宿主机。

## 用户与财务

实例归属、共享权限、访问密钥、配额重算和财务插件均由主控管理。插件支持 IDCSmart、SwapIDC、Easypanel 和 VistaPanel 等系统。

## 任务与运维

- 耗时操作通过异步任务执行，可查询进度或取消；
- 资源删除使用墓碑（tombstone）和对账（outbox）记录，失败任务可重试；
- 日志写入文件和数据库，可按主机或实例检索；
- 升级时替换主控二进制，数据目录单独保留。

## 扩展方式

主控、前端、Agent 和插件基于 AGPLv3 发布。扩展入口包括：

- 实现 `HostDriver` 接口，添加平台驱动；
- 调用主控 REST API，开发财务插件；
- 扩展 `opidcs` 命令表，添加运维命令。

## 方案比较

| 维度 | OpenIDCS | 单平台面板（如 PVE 自带） | 通用云管平台 |
|---|---|---|---|
| 多平台纳管 | 10+ 平台 | 单一平台 | 通常支持多平台 |
| 部署成本 | 单二进制 + SQLite | 中 | 高，依赖多组件 |
| 财务插件 | 已提供多种插件 | 通常无 | 通常需定制 |
| 二次开发 | Go + React | 受产品限制 | 视产品而定 |

仅使用一种虚拟化平台且不对外提供资源销售时，平台自带面板通常更合适。需要同时管理多种平台或接入财务系统时，可评估 OpenIDCS。
