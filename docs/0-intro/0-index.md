# 项目简介

OpenIDCS 是开源 IDC 虚拟化管理平台，由 CloudHost 主控、FrontPage 浏览器控制台、CloudInit 虚拟机 Agent 和 FSPlugins 财务系统插件组成。CloudHost 管理宿主机、实例、网络、用户、配额和后台任务。
